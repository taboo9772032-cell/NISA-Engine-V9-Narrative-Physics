# 🛠️ NISA Engine V9: 劇情編排模組 (Scenario Architect) 使用手冊

本模組為 NISA Engine V9 的「導航層」，負責在進入 **方案 B (全自動化管線)** 前，產出具備物理約束的劇情藍圖。它將敘事需求轉化為底層物理參數，作為核心引擎與 LLM 渲染器的輸入源。

## 1. 核心物理變量說明 (Physics Parameters)

本模組產出的 JSON 包含以下三大核心維度，用以控制敘事物理環境：

|**參數名稱**|**符號**|**物理定義**|**敘事表現**|
|---|---|---|---|
|**資訊熵**|$H$|系統混亂度與不透明度。|決定懸疑感、情報揭露速度與真相完整度。|
|**動態張力**|$TNS$|$[0, 1]$ 區間的壓力水位。|決定敘事節奏、情感壓迫感與高潮爆發閾值。|
|**字數預算**|$WC$|單一章節的文字長度限制。|決定情節的細膩度與渲染層的資訊密度。|

---

## 2. 劇情類型矩陣 (Genre Matrix)

腳本內建四種預設的小說類別，各自具備獨特的初始參數與演化曲線：

- **歷史權謀 (Historical_Strategy)**：高 $H$、低 $TNS$。強調對白潛台詞與長篇大論的政治佈局。
    
- **武俠動作 (Wuxia_Action)**：低 $H$、高 $TNS$。強調高頻率的動作碰撞與鋸齒狀的節奏起伏。
    
- **懸疑驚悚 (Suspense_Thriller)**：極高 $H$、持續中高 $TNS$。資訊熵隨劇情推進發生「坍縮式」揭露。
    
- **爽文模式 (Power_Fantasy)**：極低 $H$、極低 $TNS$。強調位能 ($POW$) 的絕對釋放與極速節奏。
    

---

## 3. 使用方式 (Usage)

### 3.1 檔案配置

將 `NISA_Scenario_Architect.py` 放置於 `NISA-Engine-V9/Scenario_Director/` 目錄下。

### 3.2 呼叫實例

透過外部腳本呼叫編排器，生成指定章節的物理藍圖：

Python

```
from Scenario_Director.NISA_Scenario_Architect import NISAScenarioArchitect

# 初始化
architect = NISAScenarioArchitect()

# 生成歷史權謀類別、第 1 章的參數
blueprint = architect.generate_chapter_config("Historical_Strategy", 1)

print(blueprint)
```

## 4. 方案 B 自動化工作流 (Workflow)

在全自動化管線中，本腳本的產出將驅動後續環節：

1. **藍圖產出**：腳本生成包含 $H, TNS, WC$ 的 JSON 檔案。
    
2. **關係修正**：LLM 讀取 JSON 後，依據張力與熵值，自動修正角色間的 $BND$ (羈絆) 或 $LOA$ (忠誠) 向量。
    
3. **物理結算**：核心引擎依據修正後的向量計算 $RES$ (資源) 與 $PRD$ (尊嚴) 損耗。
    
4. **最終渲染**：LLM 根據所有物理數據，自動產出小說文本。
